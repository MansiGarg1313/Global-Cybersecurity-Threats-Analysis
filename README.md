# Global-Cybersecurity-Threats-Analysis
# 🌐 Cybersecurity Threat Analytics Dashboard (2015–2024)

This project presents a comprehensive Tableau-based analysis of **global cybersecurity threats** over a 10-year period. The objective was to extract actionable insights from cybercrime data by identifying high-risk regions, industries, attack types, and vulnerabilities — with a focus on forensic-level analytics.

---

## 📊 Dashboards Overview

### 1. **Attack Insights**
- Visualizes global attack density using a world map
- Highlights most common attack types (e.g., DDoS, Phishing)
- Shows financial loss by industry and user impact trends over years

### 2. **Financial & Resolution Analysis**
- Correlation between affected users and financial losses
- Average resolution time by country
- Effectiveness of defense mechanisms like Firewall, VPN, AI-based detection

### 3. **Risk & Vulnerability**
- Root causes of cyberattacks (Social Engineering, Zero-day, etc.)
- Heatmap of insider threats by industry
- Boxplot of response time distribution by attack type

### 4. **Trend Analysis**
- Year-over-year trend in total financial losses
- Attack source trends (Nation-state, Insider, Hacker groups)

---

## 🧠 Tools & Skills Used

- **Tableau Public** for visualization and storytelling
- **Data Cleaning** and transformation in Excel/Python
- Advanced visual elements: boxplots, trend lines, map charts, filters
- KPI design and executive dashboarding

---

## 🔍 Key Insights

- IT and Banking sectors suffer the highest financial losses
- Insider threats are most frequent in Banking & Education sectors
- Nation-state attacks cause the largest average losses
- There's a strong correlation between user impact and financial damage

- Mock dataset created for project simulation (can be adapted for real use cases)
- Includes: Country, Year, Attack Type, Target Industry, Financial Loss, Users Affected, Resolution Time, Attack Source, Root Cause, Defense Mechanism
